`tests/browser-check.cjs`를 실제 Chrome에서 실행했습니다.

- 1440×900 및 1920×1080 화면 렌더링과 캡처.
- 390×844 모바일에서 페이지 전체 가로 넘침 없음. 테이블은 내부 가로 스크롤.
- 지역 선택, 확대·축소·지도 초기화, 우측 상세 닫기·열기.
- 시간 프리셋, 시간 슬라이더, Production/Staging 선택.
- 위험도·탐지 소스·검색 필터, 빈 결과와 필터 초기화.
- 승인 취소 시 상태 유지.
- 실행 성공 후 해결되지 않고 재검증 대기 상태로 전이.
- DB 이벤트 재검증 통과 및 해결.
- Trivy 이벤트 재검증 실패 및 잔여 취약점 2개 유지.
- 메뉴 5개 전환, 선택 상태 및 실제 콘텐츠 변경.
- 현재 필터 목록과 CSV 데이터 행 수 일치.
- 지역 상세 총계, 위험도 합계, 테이블 행 수 일치.
- 글로벌 항목 지도 좌표 미표시.
- 지도 데이터 네트워크 오류를 강제로 발생시킨 뒤 오류 표시 및 재시도 복구.
- 모션 허용/감소 설정에 따라 pulse 애니메이션 활성/비활성.
- 키보드 Enter로 지도 지역 선택 후 포커스 유지.
- 모달 중앙 배치, Escape 닫기.
- 브라우저 JavaScript 예외 없음.

## Flask 경로 검증

Flask 3.1.3 환경에서 `tests/flask-check.py`를 실행했습니다. 앱 팩토리를 통해 `/`, `/health`와 지도·차트·CSS·모듈 파일의 HTTP 200 응답을 확인했습니다. `/health`의 `mode=demo`, `aws_connected=false`를 확인했습니다. 현재 미리보기는 Python 내장 로컬 서버에서도 동일 프론트엔드를 제공합니다.

## 시각 검토와 수정

사진과 영상에서 추출한 주요 장면을 확인한 뒤, 지도 중심 비율, 얇은 내비게이션, 청록색 강조, 원형 게이지·막대·도넛, 우측 상세 구조를 구현했습니다.

## 검증 범위 밖
