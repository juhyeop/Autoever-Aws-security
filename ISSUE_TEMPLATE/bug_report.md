## 🐛 버그 설명
어떤 버그가 발생했는지 명확하고 간결하게 설명해주세요.

## 🔍 재현 방법
버그를 확인하기 위해 거쳐야 할 단계를 순서대로 적어주세요.
1. '...' 페이지/기능으로 이동합니다.
2. '...' 버튼/명령어를 실행합니다.
3. 에러 메시지나 문제가 발생하는 것을 확인합니다.

## 📸 예상되는 정상 동작
원래는 어떻게 동작해야 하는지 작성해주세요.

## 💻 작업 환경
- OS: [예: Windows, macOS, Linux]
- 버전: [예: Terraform v1.5.0, 브라우저 버전 등]

## 📎 추가 컨텍스트 (스크린샷, 에러 로그)
문제 상황을 이해하는 데 도움이 되는 스크린샷이나 텍스트 에러 로그가 있다면 여기에 첨부해주세요.
